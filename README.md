# Ahilyanagar Agri-Tech AI 🌾🚀

An AI-powered Machine Learning tool built to help farmers in Ahilyanagar (Maharashtra) predict APMC onion market prices based on supply and weather conditions, along with actionable selling advice.

### Features:
- **Multiple Linear Regression (Scikit-Learn):** Predicts market rates per quintal using historical supply and weather impact data.
- **AI Decision Engine:** Provides clear sell/hold recommendations to maximize farmer profits.
